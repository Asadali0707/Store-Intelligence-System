System Architecture
📹

CCTV Ingestion

OpenCV-based video reader processes frames at 5 FPS. Supports RTSP streams and MP4 files. Concurrent camera feeds via threading.

🤖

Person Detection

YOLOv8n (nano) for real-time detection + ByteTrack for multi-object tracking. Runs on CPU with ONNX for portability.

🔁

Re-entry Logic

Track ID + appearance embedding (ReID) + 5-minute cooldown window to deduplicate re-entrants. Staff excluded via zone-based rules.

📤

Event Streaming

Structured JSON events written to Redis Streams. Schema: {event_id, track_id, event_type, timestamp, zone, confidence}.

📊

Analytics Engine

Session aggregation, funnel computation, and anomaly detection run on event stream. SQLite for persistence, in-memory for speed.

🌐

REST API

FastAPI server exposing /metrics, /funnel, /events, /anomalies, /heatmap. CORS-enabled. Response cached 30s.
